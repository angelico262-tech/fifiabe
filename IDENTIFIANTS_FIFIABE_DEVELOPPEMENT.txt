IMPORTANT — SÉCURITÉ
--------------------
Ces identifiants sont des identifiants de développement créés par backend/prisma/seed.ts.
Ils ne doivent pas être utilisés tels quels en production.

Avant le déploiement public :
- remplacer tous les mots de passe par des mots de passe uniques ;
- ne jamais publier ce fichier dans GitHub ou dans un dossier public ;
- conserver DATABASE_URL et JWT_SECRET uniquement dans .env ;
- supprimer ou désactiver les comptes de test inutiles ;
- activer une politique de changement de mot de passe pour le personnel.
